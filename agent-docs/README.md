# Документация парсера для кодинг-агентов

Парсер — отдельный Python-сервис: раз в минуту забирает заказы из Etsy API и отправляет
их в бэкенд SouvTech CMS. Общая картина системы (бэкенд, фронт, парсер, бот, сервера) —
в `backend/agent-docs/overview.md`.

Читай по задаче, файлы короткие:

| Файл | Когда читать |
|---|---|
| [parser-loop.md](parser-loop.md) | Любая правка `src/parser.py`: цикл, окно заказов, недельная догрузка, статусы, ошибки, точки входа |
| [order-payload.md](order-payload.md) | Что именно уезжает в бэкенд и как бэкенд это обрабатывает (создание/обновление заказа, склад) |
| [etsy-auth-and-shops.md](etsy-auth-and-shops.md) | Токены Etsy, `shops.json`, на каком сервере какой магазин, лимиты, что нельзя делать |
| `../../backend/agent-docs/etsy-api.md` | Разовые запросы к Etsy API руками, что Etsy отдаёт по доставке |

Парсер нельзя проверить локально: нужны токены магазинов, а запросы к Etsy идут только
с сервера, где крутится парсер этого магазина. Проверяй код статически и через бэкенд
(эндпоинт `POST /parser/orders/upload/` можно дёргать локально с тестовым payload).

## Поддержание актуальности
Документация правится вместе с кодом: меняешь цикл, константы, статусы, поля payload,
переменные окружения или расположение магазинов по серверам — обнови соответствующий файл
в той же ветке. Нашёл расхождение доки с кодом — исправь доку.
